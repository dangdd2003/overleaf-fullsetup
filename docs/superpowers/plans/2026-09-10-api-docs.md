# API Docs Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a themed, in-app API reference page at `/api-docs` (backed by a raw spec at `/api/v0/openapi.json`) documenting the Git Bridge and Personal Access Token APIs, reachable from the Help menu directly below the existing "Documentation" link — all disabled by default behind `API_DOCS_ENABLED`.

**Architecture:** A new self-contained module at `services/web/modules/api-docs/`, following the exact pattern already used by `admin-user-management` (a web-hosted module that renders its own full page via `layout-react`). The OpenAPI 3.0 spec is hand-written as JSON (no new YAML dependency), served as-is, and also used to render the themed page client-side.

**Tech Stack:** Node.js/Express (`.mjs`, ESM), Pug views, React/TSX, Vitest for unit tests, Overleaf's existing `ol-*` themed component library (`OLPageContentCard`, `OLRow`, `OLCol`, `OLBadge`).

**Spec:** `overleaf/docs/superpowers/specs/2026-09-10-api-docs-design.md`

## Global Constraints

- Scope is exactly 9 endpoints: 6 Git Bridge (`GET /oauth/token/info`, `GET /api/v0/docs/:projectId`, `GET /api/v0/docs/:projectId/saved_vers`, `GET /api/v0/docs/:projectId/snapshots/:versionId`, `GET /api/v0/docs/:projectId/file/:fileId`, `POST /api/v0/docs/:projectId/snapshots`) plus 3 Personal Access Token (`POST/GET /user/personal-access-tokens`, `DELETE /user/personal-access-tokens/:tokenId`). No MCP, no internal services, no try-it-out execution.
- Spec format is `openapi.json` (JSON, not YAML) — this codebase has no YAML parser dependency; JSON is loaded via the existing `import ... with { type: 'json' }` pattern.
- Webui route: `GET /api-docs` (top-level, sibling to `/learn`). Raw spec route: `GET /api/v0/openapi.json`. Both require an authenticated session (`AuthenticationController.requireLogin()`).
- Feature flag: `API_DOCS_ENABLED` env var, default off, following the `Settings.enable<X> === undefined` lazy-init idiom.
- Module must be added to `moduleImportSequence` in `services/web/config/settings.defaults.js` unconditionally (gating happens at runtime, not at load time), matching `github-sync`.
- UI must reuse Overleaf's existing themed components (`OLPageContentCard`, `OLRow`, `OLCol`, `OLBadge` from `services/web/frontend/js/shared/components/ol/`) — no hand-rolled CSS or generic Swagger UI styling.
- Help menu button placement: cloned from the existing `documentation` `DropdownItem`/`MenuBarOption`, placed directly below it, gated by a new `ol-apiDocsEnabled` meta flag mirroring `ol-wikiEnabled`.

- [ ] **Step 1: Write the failing spec/route sync test**

This test statically scans the real router source files (regex, no execution) and asserts every route they register is documented in `openapi.json`, so the docs can't silently drift from the real API. Create `services/web/modules/api-docs/test/unit/src/OpenApiSpecSync.test.mjs`:

```js
import { describe, it, expect } from 'vitest'
import fs from 'node:fs'
import path from 'node:path'
import openApiSpec from '../../../app/src/openapi.json' with { type: 'json' }

const WEB_ROOT = path.resolve(import.meta.dirname, '../../../../..')

function extractRoutes(filePath, callPrefix) {
  const source = fs.readFileSync(filePath, 'utf8')
  const pattern = new RegExp(
    `${callPrefix}\\.(get|post|put|delete)\\(\\s*['"]([^'"]+)['"]`,
    'g'
  )
  const routes = []
  let match
  while ((match = pattern.exec(source))) {
    const [, method, expressPath] = match
    const openApiPath = expressPath.replace(/:([a-zA-Z0-9_]+)/g, '{$1}')
    routes.push({ method, path: openApiPath })
  }
  return routes
}

describe('openapi.json stays in sync with the real routers', function () {
  const gitBridgeRoutes = extractRoutes(
    path.join(WEB_ROOT, 'app/src/Features/GitBridge/GitBridgeRouter.mjs'),
    'r'
  )
  const patRoutes = extractRoutes(
    path.join(
      WEB_ROOT,
      'app/src/Features/PersonalAccessToken/PersonalAccessTokenRouter.mjs'
    ),
    'webRouter'
  )
  const allRoutes = [...gitBridgeRoutes, ...patRoutes]

  it('found at least the 9 known in-scope routes', function () {
    expect(allRoutes.length).to.be.at.least(9)
  })

  it('documents every extracted route with a matching method', function () {
    const missing = []
    for (const { method, path: routePath } of allRoutes) {
      const documented = openApiSpec.paths?.[routePath]?.[method]
      if (!documented) {
        missing.push(`${method.toUpperCase()} ${routePath}`)
      }
    }
    expect(missing, `undocumented routes: ${missing.join(', ')}`).to.deep.equal([])
  })
})
```

Create `services/web/modules/api-docs/frontend/js/components/root.tsx`:

```tsx
import { useEffect, useState } from 'react'
import { getJSON } from '@/infrastructure/fetch-json'
import OLPageContentCard from '@/shared/components/ol/ol-page-content-card'
import OLRow from '@/shared/components/ol/ol-row'
import OLCol from '@/shared/components/ol/ol-col'
import OLBadge from '@/shared/components/ol/ol-badge'

type OpenApiOperation = {
  summary?: string
  description?: string
  responses?: Record<string, { description?: string }>
}

type OpenApiSpec = {
  info: { title: string; version: string }
  paths: Record<string, Record<string, OpenApiOperation>>
}

const METHOD_BADGE_BG: Record<string, string> = {
  get: 'info',
  post: 'success',
  put: 'warning',
  delete: 'danger',
}

function EndpointCard({
  path,
  method,
  operation,
}: {
  path: string
  method: string
  operation: OpenApiOperation
}) {
  return (
    <OLCard className="mb-3">
      {Body => (
        <Body>
          <div className="d-flex align-items-center gap-2 mb-2">
            <OLBadge bg={METHOD_BADGE_BG[method] || 'secondary'}>
              {method.toUpperCase()}
            </OLBadge>
            <code>{path}</code>
          </div>
          {operation.summary && <h3 className="h5">{operation.summary}</h3>}
          {operation.description && <p>{operation.description}</p>}
          <pre className="mb-0">
            <code>{`curl -H "Authorization: Bearer $OVERLEAF_TOKEN" \\\n  "$OVERLEAF_URL${path.replace(/\{[^}]+\}/g, m => m)}"`}</code>
          </pre>
        </Body>
      )}
    </OLCard>
  )
}

function ApiDocsPageRoot() {
  const [spec, setSpec] = useState<OpenApiSpec | null>(null)

  useEffect(() => {
    getJSON<OpenApiSpec>('/api/v0/openapi.json').then(setSpec)
  }, [])

  if (!spec) {
    return null
  }

  return (
    <div className="container">
      <OLRow>
        <OLCol xl={{ span: 10, offset: 1 }}>
          <OLPageContentCard>
            <div className="page-header">
              <h1>{spec.info.title}</h1>
            </div>
            {Object.entries(spec.paths).map(([path, operations]) =>
              Object.entries(operations).map(([method, operation]) => (
                <EndpointCard
                  key={`${method} ${path}`}
                  path={path}
                  method={method}
                  operation={operation}
                />
              ))
            )}
          </OLPageContentCard>
        </OLCol>
      </OLRow>
    </div>
  )
}

export default ApiDocsPageRoot
```

Note: this imports `OLCard` from `@/shared/components/ol/ol-card` — add that import line at the top alongside the others (`import OLCard from '@/shared/components/ol/ol-card'`).
